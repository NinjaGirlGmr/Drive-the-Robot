This is a robot seen from above, like in tools FRC teams use (AdvantageScope, PathPlanner). The circles are swerve wheels.

teamName is a String: a name or phrase. It never changes during the match.
hasGamePiece is a boolean: yes or no. Shoot and it becomes false.
score is an int: a whole number. It goes up by one each shot.
matchTime is a double: a number with a decimal point. It counts down.
